# Supermercado Fácil

## Descrição do Projeto
O **Supermercado Fácil** é uma aplicação desktop desenvolvida em Python com a biblioteca Tkinter. O objetivo principal é facilitar a gestão de listas de compras consoante o perfil da residência do utilizador (Solo, Duo ou Família). O sistema carrega matrizes pré-definidas de produtos e permite a adição, remoção e visualização de um resumo da compra.

## Pré-requisitos
* Python 3.x instalado no sistema.
* Biblioteca `tkinter` (geralmente nativa na instalação do Python).

## Como Executar
1. Clone este repositório para a sua máquina local.
2. Abra o terminal na diretoria do projeto.
3. Execute o comando:
   ```bash
   python main.py
