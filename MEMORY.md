
# Memória de Trabalho e Contexto Arquitetural

## Decisões Técnicas
* **Linguagem:** Optou-se pelo uso de Python pela sua legibilidade e facilidade de integração com ferramentas de Inteligência Artificial no VS Code durante a fase de desenvolvimento.
* **Interface Gráfica:** Utilizou-se o `Tkinter` por ser a biblioteca padrão do Python, não exigindo a instalação de dependências externas pesadas, garantindo que o programa corre em qualquer máquina facilmente.
* **Estrutura de Dados:** 
  * Os perfis foram armazenados num vetor (lista 1D).
  * Os itens das listas de compras pré-definidas foram estruturados numa matriz tridimensional (lista de matrizes 2D), permitindo uma rápida atribuição de dados consoante o perfil escolhido pelo utilizador através de uma cópia em memória.

## Ferramentas de IA Utilizadas
O desenvolvimento deste projeto contou com o auxílio de modelos de IA (Gemini/OpenRouter) integrados no VS Code para agilizar a criação da estrutura base do Tkinter e a lógica de manipulação das matrizes.
